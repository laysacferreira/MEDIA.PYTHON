# 📊 Projeto: Cálculo de Média de 3 Notas em Python

## 🧠 Sobre o Projeto

Este projeto foi desenvolvido em Python com o objetivo de calcular a média de três notas informadas pelo usuário. Ele simula uma situação comum do ambiente escolar, onde é necessário avaliar o desempenho de um aluno com base em suas notas.

## 📄 Descrição

O programa solicita ao usuário:

* O nome do aluno
* Três notas

Após isso, ele realiza o cálculo da média aritmética e exibe o resultado na tela de forma organizada.

Além disso, o sistema pode indicar a situação do aluno, como:

* ✅ Aprovado
* ⚠️ Recuperação
* ❌ Reprovado

Tudo isso utilizando conceitos básicos da programação em Python, como:

* Entrada de dados (`input`)
* Conversão de tipos (`float`)
* Operações matemáticas
* Estruturas condicionais (`if`, `elif`, `else`)
